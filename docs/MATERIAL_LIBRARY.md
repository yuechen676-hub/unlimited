# 数据驱动的材质库

[← 文档首页](README.md) · 相关：[AIGC 贴图流程](AIGC.md) · [工具链](TOOLS.md)

## 1. 要解决的问题

一种质地在游戏里同时出现在四个地方：**器物本身**、**槽位下的桌面样片**、**放对后的缩小模型**、**射线照到时的敲击声**。手工维护时，常常出现视觉已经改了、样片或声音还是旧的。三个房间共 18 件器物，这类不一致很难靠肉眼发现。

## 2. 结构：共享材质族 + 房间配置表

```text
RevealMaterialLibrary（共享，不含任何房间信息）
  └─ Entry: id / 视觉描述 / 底色贴图 / 揭示模板 / 样片模板 / 敲击声 / 来源记录

RevealPuzzleTable（每个房间一张）
  ├─ materialLibrary → 引用上面的库
  ├─ families: 本房间用到的质地 → 同步出的房间独立材质
  ├─ pairings: itemId → familyId
  └─ 揭示半径、贴图密度、样片平铺、自发光等房间参数
```

一个 `familyId` 同时派生出四种输出：

| 输出 | 用在哪里 |
|---|---|
| 器物揭示材质 | 架子上的器物，射线照射时露出 |
| 桌面样片材质 | 槽位下方，提示这里要什么质地 |
| 缩小模型材质 | 放对后在槽位上铺开 |
| 敲击声 | 射线停留时播放 |

同步后的房间材质是独立资源，调整某个房间不会改动共享模板；需要覆盖参数时复制模板，而不是直接修改共享资源。

一号房的 8 种质地是木、漆、瓷、石、陶、铜、玉、竹。每种质地的敲击声从音效素材中剪出起音段，并统一响度（剪切点、长度、增益都记录在 `SOURCES.txt` 里）。8 种声音听起来音量一致，玩家只需要分辨音色。

## 3. 新增一种质地

1. 在材质库中建立稳定 ID，配置贴图、模板和声音；
2. 在房间配置表中绑定器物 ID 与材质族；
3. 运行编辑器同步命令，生成房间材质、器物材质和槽位样片；
4. 检查碰撞体、Renderer 层级和射线可命中的范围；
5. 验证四种状态：探索、切换目标、正确放置、整房恢复。

第 3 步之后的检查由 [审计工具](TOOLS.md) 和 [PlayMode 测试](VALIDATION.md) 完成。

## 4. 设计取舍

| 选择 | 原因 |
|---|---|
| 材质库不含房间信息 | 同一种「铜」可以在多个房间复用，房间参数（密度、半径）单独配置 |
| 房间材质是同步生成的独立资源 | 允许单个房间微调，又不会污染模板 |
| 用字符串 ID 而不是直接引用材质 | 配置表可读，审计时能直接对照；框架里的槽位判定本来也用字符串 ID |
| 来源记录挂在材质族上 | 每种质地的贴图从哪里来，在一个地方就能查到，见 [AIGC](AIGC.md) |
